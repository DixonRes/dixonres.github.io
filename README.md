## Website Notes

The website documentation has been updated to match the current `drsolve` CLI:

- `Install` now recommends FLINT `3.5.0`, includes explicit FLINT build steps, and clarifies that the PML code used by DRsolve is bundled in-tree rather than requiring a separate installation.
- `Usage` now places `Random Mode` before `Complexity`, adds `--seed` coverage for reproducible random systems, and documents the `-r -c` / `-r --comp` combination for random complexity analysis.
- Older wording that implied a separate PML install or outdated FLINT baseline has been removed.
